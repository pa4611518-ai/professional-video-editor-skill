# Edit decision list (EDL) workflow

Use this reference when the source has multiple scenes, meaningful dialogue, a strict duration, or a complex creative brief. For a simple trim, keep the plan proportional.

## Before editing

1. Inventory all source files and record their duration, frame size, frame rate, orientation, audio streams, and any variable-frame-rate concerns.
2. Watch or inspect the source sufficiently to understand its story. Use a contact sheet as a navigation aid, not as a substitute for playback.
3. If speech drives the edit, create a timestamped transcript with a locally available tool when possible. Verify high-impact words, names, prices, quantities, negations, and calls to action against the source audio.
4. Map source time to intended output time. Mark every planned removal, retained moment, reordered section, crop/reframe, title, caption, audio change, and transition.
5. State the reason for each non-trivial change and its acceptance check.

## Suggested EDL fields

| Field | Meaning |
|---|---|
| ID | Stable decision identifier |
| Source in/out | Source timecodes, when measurable |
| Action | Keep, trim, remove, reorder, reframe, repair, caption, mix, or leave unchanged |
| Rationale | Why the decision serves the brief |
| Risk | What could go wrong, e.g. lost context, clipped words, hidden product |
| Verification | How to check the rendered result |

Do not fabricate timecodes. If a tool cannot inspect the exact point, record an approximate range and verify during playback before committing the cut.

## Execution discipline

- Preserve a copy of the original and create a new output for each meaningful revision.
- Build the edit in logical passes: structure, picture, audio, color, graphics, final export. Combine passes when simpler, but do not skip the checks.
- Render a short representative preview before a costly full render when timing, fonts, complex filters, or compositing could fail.
- Update only affected EDL entries if a new issue appears. Do not let a local fix silently change the whole creative direction.
- Keep a concise changelog for significant revisions and final output settings.
